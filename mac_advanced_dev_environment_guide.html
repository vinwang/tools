Mac 高级开发环境标准方案

适用于 Java / PHP / Python / Node.js / Golang / MySQL / PostgreSQL / Redis / Hyperf / Laravel 多语言开发环境。

Apple Silicon Homebrew PHP 多版本 Python 多版本 Java Node.js Golang Redis

一、整体架构方案

组件 推荐方案 原因
PHP 多版本 Homebrew 灵活、稳定、适合 Swoole/Loader
Python 多版本 pyenv 版本隔离彻底，虚拟环境友好
Java 多版本 jenv 切换方便
Node 多版本 fnm 超轻量、启动快
Golang 多版本 Homebrew + g 安装简单，g 支持多版本切换
MySQL Homebrew 省内存
PostgreSQL Homebrew 稳定
Redis Homebrew 简单可靠
该方案比 Docker Desktop 节省大量内存，非常适合 Mac 开发环境。

二、安装 Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zshrc
source ~/.zshrc

三、PHP 多版本安装

安装 PHP 仓库

brew tap shivammathur/php

安装多个 PHP 版本

brew install shivammathur/php/php@8.0
brew install php@8.1
brew install php@8.3

查看版本

brew list | grep php

切换 PHP

brew unlink php@8.3
brew link --overwrite --force php@8.0

验证

php -v

四、PHP 配置与扩展安装

查看当前 PHP 版本

php -v

查看 PHP 配置文件

php --ini

查看 php.ini 路径

Loaded Configuration File:
/opt/homebrew/etc/php/8.0/php.ini

查看 conf.d 扩展目录

/opt/homebrew/etc/php/8.0/conf.d

查看 PHP 扩展目录

php-config --extension-dir

查看当前已加载扩展

php -m

查看单个扩展信息

php --ri swoole
php --ri redis

安装编译依赖

brew install autoconf
brew install automake
brew install libtool
brew install pcre2
brew install openssl

查看 pecl 对应 PHP 版本

pecl version

安装 Swoole4（PHP8.0 推荐）

pecl install swoole-4.8.13

安装 Redis 扩展

pecl install redis

安装 Xdebug

pecl install xdebug

安装 MongoDB 扩展

pecl install mongodb

推荐扩展安装选项

扩展功能 推荐选项
igbinary no
zstd no
lz4 no
msgpack no

扩展配置方式（推荐）

nano /opt/homebrew/etc/php/8.0/conf.d/ext-redis.ini

写入：

extension=redis

Swoole Loader 配置

nano /opt/homebrew/etc/php/8.0/php.ini

追加：

extension=swoole_loader_80_nts_arm64.so

验证扩展是否成功加载

php -m | grep swoole
php -m | grep redis
不同 PHP 版本的扩展不能混用，例如 PHP8.0 扩展不能用于 PHP8.3。
推荐使用 conf.d 独立管理扩展，而不是全部写进 php.ini。

五、MySQL 安装

安装

brew install mysql

启动

brew services start mysql

登录

mysql -uroot

查看 MySQL 状态

brew services list

登录 MySQL

mysql -uroot -p

设置 root 密码

ALTER USER 'root'@'localhost'
IDENTIFIED BY 'Root@123456';

查看密码策略

SHOW VARIABLES LIKE 'validate_password%';

降低密码复杂度（开发环境）

SET GLOBAL validate_password.policy=LOW;
SET GLOBAL validate_password.length=6;

创建开发用户

CREATE USER 'dev'@'%'
IDENTIFIED BY 'Dev@123456';
GRANT ALL PRIVILEGES ON *.*
TO 'dev'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;

创建数据库

CREATE DATABASE shop_db
DEFAULT CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

查看用户

SELECT user,host FROM mysql.user;

查看数据库

SHOW DATABASES;

六、PostgreSQL 安装

安装 PostgreSQL

brew install postgresql@17

启动 PostgreSQL

brew services start postgresql@17

查看状态

brew services list

进入 PostgreSQL

psql postgres

创建用户（推荐）

CREATE ROLE dev
WITH LOGIN
PASSWORD 'Dev@123456'
CREATEDB;

创建数据库

CREATE DATABASE shop_db
OWNER dev;

授权

GRANT ALL PRIVILEGES
ON DATABASE shop_db
TO dev;

查看用户

\du

查看数据库

\l

退出 PostgreSQL

\q
PostgreSQL 推荐为每个项目创建独立数据库和用户。

八、Java 多版本管理（推荐 jenv）

安装 jenv

brew install jenv

配置 zsh

echo 'export PATH="$HOME/.jenv/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(jenv init -)"' >> ~/.zshrc
source ~/.zshrc

安装多个 JDK

brew install openjdk@17
brew install openjdk@21

配置 JAVA_HOME

sudo ln -sfn /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk
sudo ln -sfn /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk

添加到 jenv

jenv add /Library/Java/JavaVirtualMachines/openjdk-17.jdk/Contents/Home
jenv add /Library/Java/JavaVirtualMachines/openjdk-21.jdk/Contents/Home

查看已安装 Java

jenv versions

全局切换 Java

jenv global 17

项目级切换 Java

jenv local 21

验证

java -version
mvn -v
jenv 比 SDKMAN 更适合长期本地开发环境管理，并且与 Homebrew 更兼容。

十、Python 多版本管理（推荐 pyenv）

安装 pyenv

brew install pyenv

配置 zsh

echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init -)"' >> ~/.zshrc
source ~/.zshrc

查看可安装的 Python 版本

pyenv install --list | grep "^\s*3\."

安装多个 Python 版本

pyenv install 3.10.14
pyenv install 3.11.9
pyenv install 3.12.4

查看已安装版本

pyenv versions

设置全局默认版本

pyenv global 3.12.4

项目级切换（在项目目录下执行）

pyenv local 3.10.14

会在当前目录生成 .python-version 文件，进入该目录后自动切换。

验证

python --version
which python

虚拟环境管理（推荐 venv）

# 创建虚拟环境
python -m venv .venv
# 激活
source .venv/bin/activate
# 退出
deactivate

pip 加速（国内镜像）

pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

常用包安装示例

pip install requests numpy pandas fastapi uvicorn
推荐每个项目使用独立虚拟环境（.venv），不要在全局 Python 下直接 pip install。
不要使用系统自带的 Python（/usr/bin/python3），避免影响系统工具。

十一、Golang 开发环境安装

安装 Go（Homebrew，单版本，推荐大多数场景）

brew install go

验证

go version

查看 Go 环境变量

go env

配置 GOPATH / GOBIN

mkdir -p ~/go
echo 'export GOPATH="$HOME/go"' >> ~/.zshrc
echo 'export PATH="$GOPATH/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

配置国内代理（推荐，加速模块下载）

go env -w GOPROXY=https://goproxy.cn,direct
go env -w GO111MODULE=on
go env -w GOSUMDB=off

升级 / 卸载 Go

# 升级到最新版
brew upgrade go
# 卸载
brew uninstall go

Golang 多版本管理（推荐 g，类似 pyenv/fnm 的思路）

如果需要在多个项目间切换不同的 Go 版本，推荐使用 g（voidint/g）。

安装 g（会自动接管 GOROOT）

curl -sSL https://raw.githubusercontent.com/voidint/g/master/install.sh | bash

配置 zsh

echo 'source "$HOME/.g/env"' >> ~/.zshrc
source ~/.zshrc

查看可安装版本

g ls-remote

安装多个 Go 版本

g install 1.21.13
g install 1.22.6
g install 1.23.4

查看已安装版本

g ls

切换 Go 版本（全局）

g use 1.23.4

验证

go version
which go
使用 g 管理多版本前，建议先卸载 Homebrew 安装的 go（brew uninstall go），避免 PATH 中出现两个 go 二进制互相冲突。

Go Modules 常用命令

# 初始化模块
go mod init example.com/myproject
# 整理依赖
go mod tidy
# 查看依赖图
go mod graph
# 下载依赖到本地缓存
go mod download

常用开发工具安装

# 代码格式化 / 静态检查（golangci-lint）
brew install golangci-lint
# 热重载工具（air，改代码自动重启服务）
go install github.com/air-verse/air@latest
# 调试工具 delve
go install github.com/go-delve/delve/cmd/dlv@latest

常用项目结构（Web/微服务）

myproject/
├── cmd/
│   └── myproject/
│       └── main.go
├── internal/
│   ├── config/
│   ├── handler/
│   ├── service/
│   └── repository/
├── pkg/
├── go.mod
└── go.sum

快速创建一个 Hello World 项目验证环境

mkdir -p ~/Code/golang/hello && cd ~/Code/golang/hello
go mod init hello
cat > main.go << 'EOF'
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go on macOS!")
}
EOF
go run main.go
日常开发单一版本用 Homebrew 的 go 即可；只有当你需要在不同项目间维护不同 Go 版本（比如老项目锁定 1.21，新项目用 1.23）时才引入 g，避免过度复杂化。

十二、项目自动切换 PHP 版本（推荐）

安装 direnv

brew install direnv

配置

echo 'eval "$(direnv hook zsh)"' >> ~/.zshrc
source ~/.zshrc

项目目录创建 .envrc

export PATH="/opt/homebrew/opt/php@8.0/bin:$PATH"
export PATH="/opt/homebrew/opt/php@8.0/sbin:$PATH"

启用

direnv allow
进入项目目录后会自动切换 PHP 版本。

十五、最佳实践

  • 不要使用 sudo 启动 brew services
  • 不同 PHP 项目使用不同 PHP 版本
  • 扩展按 PHP 版本分别安装
  • 数据库统一使用 brew 管理
  • 尽量避免 Docker Desktop 常驻
  • Hyperf/Swoole 项目固定 PHP8.0 + Swoole4
  • Laravel/新项目推荐 PHP8.3
  • Node 项目优先使用 Node22 LTS
  • Python 每个项目使用独立虚拟环境（.venv），通过 pyenv local 固定版本
  • Go 项目统一使用 go.mod 管理依赖，不使用 GOPATH 模式开发
  • MySQL/PostgreSQL/Redis 使用当前用户启动
这是目前 Mac 开发者最省内存、最稳定、最适合 Java + PHP + Node + Go 全栈开发的方案之一。
