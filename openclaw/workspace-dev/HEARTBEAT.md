# HEARTBEAT.md - Dev 定时任务

## CI/CD 健康检查 (每 4 小时)

每 4 小时执行一次：

1. 检查构建状态
   - 是否有失败的构建
   - 是否有长时间未合并的 PR

2. 检查关键服务
   - Gateway 运行状态
   - 关键接口响应时间

3. 如有异常
   - 记录技术债务
   - 通知 Milo

## PR 审查 (每日)

每日执行：

1. 检查待审查 PR
   - 优先级排序
   - 估计审查时间

2. 技术债务追踪
   - 记录发现的代码问题
   - 建议改进方案

## 周度技术报告 (每周五)

每周五执行：

1. 汇总本周技术进展
2. 列出技术债务清单
3. 提出下周改进计划
4. 发送给 Milo
